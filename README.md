# BioEat — предзаказ питания в столовой РОСБИОТЕХ

Веб-приложение, которое убирает очередь в столовой: обучающийся собирает заказ заранее,
оплачивает его в приложении и забирает по QR-коду в окне «Экспресс-выдача» за 15 секунд.

Стек: **Python 3.12 · FastAPI · PostgreSQL 16 · SQLAlchemy 2 (async)**.
Клиент — PWA без сборщика, открывается на Android, iPhone, iPad, Mac и обычном компьютере.

> **Демонстрационный режим.** Оплата имитируется на сервере: к банкам, СБП и эквайрингу
> приложение не обращается. Это осознанное решение для MVP — экраны и логика заказа
> полностью соответствуют боевому сценарию, подменён только шаг списания денег.

## Быстрый старт

### Вариант 1. Docker (рекомендуется)

```bash
docker compose up --build
```

Через полминуты приложение доступно на **http://localhost:8000**
Меню, окна выдачи и учётные записи создаются автоматически при первом запуске.

Чтобы на защите панели администратора и оператора не были пустыми, налейте демо-активность:

```bash
docker compose exec app python -m app.demo_data
```

Скрипт создаст 8 студентов и ~43 заказа за вчера, сегодня и завтра в разных статусах.
Убрать их обратно: `docker compose exec app python -m app.demo_data --reset`

Остановить: `docker compose down` · Удалить базу вместе с данными: `docker compose down -v`

### Вариант 2. Без Docker

Нужен запущенный PostgreSQL.

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

export DATABASE_URL="postgresql+asyncpg://bioeat:bioeat@localhost:5432/bioeat"
export SECRET_KEY="длинная-случайная-строка"

python -m app.demo_data          # схема + меню + демо-заказы
uvicorn app.main:app --reload
```

Если PostgreSQL под рукой нет, приложение поднимется и на SQLite — удобно для быстрой проверки:

```bash
export DATABASE_URL="sqlite+aiosqlite:///./bioeat.db"
uvicorn app.main:app --reload
```

### Открыть с телефона в одной сети

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Затем на телефоне откройте `http://<IP-компьютера>:8000`. В Safari и Chrome приложение
можно добавить на домашний экран — оно откроется как обычное мобильное приложение (PWA).

## Сценарий для защиты

1. **Вход** → карточка «Обучающийся».
2. **Главная** — витрина в стиле приложения РОСБИОТЕХ: баннеры, бонусный баланс, плитки сервисов.
3. **Меню** — 52 позиции, фильтры «ПП / Вегетарианское / Без лактозы / Без глютена / Острое»,
   поиск, карточка блюда с БЖУ и составом.
4. **Корзина** → **«Выбрать время»** — дата, окно выдачи с остатком мест, списание бонусов, комментарий кухне.
5. **Оплата** — СБП или карта. Переключатель «Смоделировать отказ банка» показывает обработку ошибки.
6. **QR-код заказа** — трекер статуса обновляется сам.
7. Со второго устройства (или в другом окне браузера) войдите **оператором** → заказ виден в колонке
   «Новые» → «Принять» → «Комплектовать» → «Готов». На экране студента всплывает «🔔 Заказ готов к выдаче».
8. Введите номер заказа в поле выдачи → **«Выдать заказ»**. Статус меняется на «Выдан».
9. **Админ-панель** → «Меню»: добавьте блюдо, поставьте остаток 0 (стоп-лист), удалите.
   Вкладка «Отчёты» покажет выручку, средний чек, топ блюд и нагрузку по окнам.

## Что умеет приложение

**Обучающийся**

- меню по категориям с фото-иконками, весом, калорийностью и БЖУ;
- фильтры по диете и поиск;
- корзина хранится на сервере — открывается одинаково на телефоне и ноутбуке;
- выбор даты (до недели вперёд) и окна выдачи с учётом свободных мест;
- бонусы: кэшбэк 5% с оплаченного заказа, списание до 30% суммы следующего;
- оплата СБП / картой (демо), сценарий отказа банка;
- QR-код выдачи и номер заказа, трекер статуса, уведомление «Заказ готов»;
- история заказов, отмена до начала комплектации.

**Оператор столовой**

- канбан очереди на выбранный день: Новые → Принятые → Комплектуются → К выдаче;
- в карточке видно состав, количество порций, группу студента и его комментарий;
- выдача по QR-коду или по номеру заказа вручную (сканер-«пистолет» работает как обычная клавиатура);
- отмена заказа с возвратом порций в наличие;
- автообновление доски каждые 7 секунд без «прыжков» интерфейса.

**Администратор**

- меню: добавление, редактирование, скрытие и удаление блюд, остатки на день и стоп-лист;
- категории: создание, порядок, видимость;
- окна выдачи: время, точка, вместимость, включение и отключение;
- отчёты: заказы, выручка, средний чек, выдано, топ блюд, нагрузка по окнам;
- сотрудники: создание операторских и административных учётных записей, смена ролей.

### Решения, на которые стоит обратить внимание

**Остатки резервируются в транзакции.** При оформлении заказа строки блюд блокируются
(`SELECT … FOR UPDATE`), поэтому два студента не могут забрать одну и ту же последнюю порцию.
При отмене порции возвращаются в наличие.

**Вместимость окна выдачи.** У каждого окна есть лимит заказов — столовая не получит
120 заказов на пятнадцатиминутную перемену. Приём на окно закрывается за 10 минут до начала выдачи.

**Идемпотентная оплата.** Повторный запрос на оплату уже оплаченного заказа не создаёт второе
списание, а возвращает текущее состояние. Это защищает от двойного нажатия и повторов сети.

**Статусы меняются только по разрешённым переходам.** Нельзя выдать неоплаченный или неготовый
заказ, нельзя «откатить» выданный. Список переходов задан в `services.ALLOWED_TRANSITIONS`.

**QR-код подписан.** Тело кода — `BIOEAT:<номер>:<nonce>:<HMAC-подпись>`. Подделать код,
не зная `SECRET_KEY`, нельзя; выдать один заказ дважды тоже нельзя.

**Цены и названия сохраняются в заказе снимком.** Если администратор поднимет цену завтра,
вчерашние чеки в истории не «поплывут».

**Удаление блюда безопасно.** По умолчанию блюдо скрывается из меню, история заказов остаётся целой.
Полное удаление блокируется, пока блюдо есть в активных заказах.

## Адаптивность

| Устройство | Как выглядит |
|-----------|--------------|
| iPhone / Android | Одна колонка, плавающая нижняя навигация, учёт «чёлки» и жестовой полосы (`safe-area`) |

## Что нужно доделать до боевого запуска

Честный список, если проект пойдёт дальше MVP:

1. **Реальный эквайринг** — СБП через банк-партнёр или платёжный агрегатор, вебхуки о статусе платежа,
   возвраты. Сейчас это `services.pay_order`, куда подставляется провайдер.
2. **Вход через учётную запись университета** (SSO), чтобы не заводить отдельные пароли.
3. **Настоящие push-уведомления** — Web Push для PWA. Сейчас статус обновляется опросом сервера.
4. **Alembic-миграции** вместо `create_all` — как только схема начнёт меняться на живых данных.
5. **Интеграция с учётом столовой** — выгрузка меню и остатков из системы комбината питания.
6. **Фотографии блюд** вместо иконок.
7. **HTTPS и защищённые cookie** на боевом домене, ограничение CORS.

## О меню

Ассортимент и цены собраны по типовому меню московской вузовской столовой: комбо-обеды, супы,
горячее, гарниры, салаты, выпечка, напитки и десерты — 52 позиции с весом, калорийностью, БЖУ
и метками диеты. Актуального меню столовой РОСБИОТЕХ в открытых источниках нет, поэтому позиции
редактируются в админ-панели: раздел «Меню» → «Добавить блюдо», остатки и стоп-лист меняются
прямо в таблице.
