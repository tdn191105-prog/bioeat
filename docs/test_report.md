# Отчёт о проверке на iOS и Android

Кому: команде РосПит перед показом столовой.
Дата: 26 октября 2026. Ветка `rospit`.

## Главное честно

- **Проверено в эмуляторах, а не на живых телефонах.** «iPhone» — движок WebKit 26.5 из
  Playwright с профилем iPhone 14 (390×664, ×3, тач); это близко к Safari, но **не настоящий
  Safari на iOS**. «Android» — Chromium 151 с профилем Pixel 7. Планшет — WebKit с профилем
  iPad (gen 7), десктоп — Chromium 1280×800.
- **Не проверено:** установка PWA «На экран Домой» на iPhone, реальная экранная клавиатура,
  чёлка и Dynamic Island, системный крупный шрифт, офлайн в Safari, работа камеры-сканера.
  Для этого ниже есть чек-лист на 15 минут для живых iPhone и Android.
- **APK** собран, но на эмуляторе и телефоне не запускался (см. `docs/mobile.md`).
- Оплата проверялась в **демо-режиме**. Боевая ЮKassa покрыта тестами с замоканным HTTP,
  с реальным тестовым магазином не запускалась: нет ключей.

## Что прогоняется автоматически

`E2E=1 pytest tests/e2e` поднимает настоящий сервер на чистой базе с демо-данными
и открывает браузеры. Скриншоты ключевых экранов — в `tests/e2e/screens/`,
сырые находки — в `tests/e2e/results.json`.

| Сценарий | iPhone (WebKit) | Android (Chromium) | Планшет (WebKit) | Десктоп 1280 |
|----------|:---:|:---:|:---:|:---:|
| Вход по демо-карточке, заголовок «РосПит» | ✅ | ✅ | ✅ | ✅ |
| Меню: фильтр «ПП», поиск «борщ», карточка блюда | ✅ | ✅ | ✅ | ✅ |
| Корзина → «Когда забрать»: у каждой перемены «приём до ЧЧ:ММ» / «приём закрыт в ЧЧ:ММ» | ✅ | ✅ | ✅ | ✅ |
| Демо-оплата → экран заказа с QR | ✅ | ✅ | ✅ | ✅ |
| История заказов | ✅ | ✅ | ✅ | ✅ |
| Отзыв 5★ с тегом и текстом после выдачи | ✅ | ✅ | ✅ | ✅ |
| Повтор заказа → корзина | ✅ | ✅ | ✅ | ✅ |
| Нет ошибок JavaScript в консоли | ✅* | ✅ | ✅* | ✅ |

\* WebKit пишет предупреждение `Viewport argument key "interactive-widget" not recognized` —
это ожидаемо: параметр нужен Chrome на Android, Safari его просто игнорирует.

**Кухня и постамат** (десктоп для кухни + iPhone для студента + эмулятор постамата): ✅
сводка перемены «собрать: …» → «Собран» → «Положен в ячейку» (ячейка №1, дверца открывается
командой) → у студента «Заказ в ячейке №1» и одноразовый QR + PIN → **код сам сменился**
через 10 с (на стенде срок жизни 20 с) → эмулятор отсканировал код, ячейка открылась →
повторный скан того же кода отклонён → после закрытия двери у студента «Выдан» и форма отзыва.

**Телефонные проверки** (iPhone и Android):

| Проверка | iPhone | Android |
|----------|:---:|:---:|
| Альбомная ориентация: главная, меню, корзина без горизонтальной прокрутки | ✅ | ✅ |
| Экран 320 px (iPhone SE): меню, оформление, заказы, профиль без горизонтальной прокрутки | ✅ | ✅ |
| Масштаб страницы 130 % (как «Масштаб текста» в Chrome) — меню не разъезжается | ✅ | ✅ |
| Service worker регистрируется | ✅ | ✅ |
| Офлайн: оболочка открывается без сети | ⚠️ не проверено** | ✅ |
| Поле ввода в фокусе → нижняя панель прячется | ✅ | ✅ |
| Цели нажатия ≥ 44×44 | ✅ после исправления | ✅ после исправления |

\** WebKit в Playwright не умеет офлайн-перезагрузку через service worker
(«WebKit encountered an internal error»), в Chromium тот же код работает. Это ограничение среды,
а не найденная ошибка. На iPhone проверить вручную (пункт 9 чек-листа).

Также по коду: `safe-area-inset-*` учитываются в шапке и нижней панели,
`viewport-fit=cover`, высоты через `100dvh` (не `100vh`, который в Safari «прыгает» с адресной строкой).

## Чек-лист на 15 минут: живые iPhone и Android

Нужны: iPhone с iOS 16.4+ (Safari), Android с Chrome, сервер по HTTPS
(см. `docs/deploy.md`), по телефону на человека.

1. **Вход (1 мин).** Открыть адрес в Safari / Chrome → экран входа с логотипом РосПит,
   демо-карточка «Обучающийся» входит. ☐ iPhone ☐ Android
2. **Меню (2 мин).** Листаются категории, липкие заголовки не дёргаются, фильтр «ПП», поиск,
   карточка блюда открывается, фото грузятся. ☐ ☐
3. **Корзина и клавиатура (2 мин).** Добавить 2 блюда → «Когда забрать» → нажать в поле
   комментария: клавиатура не закрывает поле, нижней панели нет, после «Готово» панель вернулась. ☐ ☐
4. **Отсечка (1 мин).** Под переменами «приём до ЧЧ:ММ»; закрытые — серые с «приём закрыт в». ☐ ☐
5. **Оплата и QR (2 мин).** «Оплатить» → экран заказа с QR и номером; яркость экрана достаточная
   для сканера (поднести к сканеру в столовой или к камере второго телефона). ☐ ☐
6. **Чёлка и жесты (1 мин).** Шапка не уходит под чёлку / Dynamic Island, нижняя панель не
   перекрывает полоску «Домой». ☐ ☐
7. **Поворот (1 мин).** Повернуть телефон на меню и в корзине — ничего не обрезается. ☐ ☐
8. **Крупный шрифт (2 мин).** iPhone: Настройки → Экран и яркость → Размер текста — максимум
   (и «Увеличенный текст» в Универсальном доступе); Android: «Размер шрифта» и «Масштаб» —
   максимум. Открыть меню и корзину: кнопки не наезжают друг на друга. ☐ ☐
9. **PWA и офлайн (2 мин).** iPhone: «Поделиться» → «На экран Домой» → открыть с иконки
   (имя «РосПит», иконка с логотипом), войти заново; Android: «Установить приложение».
   Включить авиарежим → открыть с иконки: открывается оболочка, вместо ошибки браузера —
   сообщение «Нет связи». ☐ ☐
10. **Кухня (1 мин, планшет).** Кабинет столовой: перемены, «Собран», «Отметить всё как
    собранное», «Печать / PDF» — лист сборки печатается на одну страницу без кнопок. ☐

Каждый ☐, который не отметился, — строка в таблице выше: что сделали, что ожидали, что
увидели, скриншот.
